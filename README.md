# Task 3: Image Captioning AI

## Project Description
This project uses an AI model to generate captions for images.

## Technologies Used
- Python
- Hugging Face Transformers
- PyTorch
- PIL (Pillow)
- Google Colab

## AI Model
Salesforce BLIP Image Captioning Base

## How It Works
1. Upload an image.
2. The AI model analyzes the image.
3. The model generates a caption describing the image.

## Example Output
Generated Caption: A photograph of many different people in black and white.
