# Task 5: Face Detection and Recognition

## Project Description
This project detects faces in images using OpenCV and a Haar Cascade classifier.

## Technologies Used
- Python
- OpenCV
- Matplotlib
- Google Colab

## Features
- Upload an image.
- Detect visible faces in the image.
- Draw green rectangles around detected faces.
- Display the total number of detected faces.

## How It Works
1. Upload a JPG or PNG image.
2. Convert the image to grayscale.
3. Run the Haar Cascade face detector.
4. Display the image with rectangles around detected faces.

## Example Output
Faces detected: 1

## Note
This project demonstrates face detection. It does not identify or verify a person's identity.
